# 术语表

| 术语 | 白话定义 | 章节 |
|---|---|---|
| 复数 | 形如 $x+iy$ 的数，也是复平面上的点/向量。 | ch01 |
| 模与辐角 | 复数到原点的距离 $r$，以及与正实轴的夹角 $\theta$；$z=re^{i\theta}$。 | ch01 |
| 共轭复数 | $z=x+iy$ 的共轭是 $\bar z=x-iy$，且 $z\bar z=\lvert z\rvert^2$。 | ch01 |
| 复变函数 | 定义域和值域都在复平面上的函数 $w=f(z)$。 | ch01 |
| 支点 | 绕一圈后函数值不复原的点，如 $\sqrt z$、$\ln z$ 的 $0$ 与 $\infty$。 | ch01 |
| 分支切割 | 从支点引出的割线，切开平面后才能选出单值分支。 | ch01 |
| 解析函数 | 在一点的邻域内处处可导的函数；解析比可导要求更强。 | ch02 |
| 柯西–黎曼方程 | $u_x=v_y$、$u_y=-v_x$，复可导的充要条件之一。 | ch02 |
| 调和函数 | 满足 $\Delta u=0$ 的函数；解析函数的实部与虚部都是。 | ch02 |
| 保角映射 | 导数非零的解析映射，局部保持角度大小与方向。 | ch02 |
| 柯西积分定理 | 单连通区域内解析函数的闭路积分为零。 | ch03 |
| 柯西积分公式 | $f(z_0)=\frac{1}{2\pi i}\oint_C\frac{f(z)}{z-z_0}dz$。 | ch03 |
| 刘维尔定理 | 全平面解析且有界的函数必为常数。 | ch03 |
| 最大模原理 | 非常数解析函数的模最大值只能在边界取到。 | ch03 |
| 泰勒级数 | 解析点附近的幂级数，收敛半径到最近奇点。 | ch04 |
| 洛朗级数 | 环形区域内允许负幂项的展开。 | ch04 |
| 孤立奇点 | $f$ 在 $z_0$ 附近解析但 $z_0$ 本身不解析；分可去、极点、本性。 | ch04 |
| 留数 | 洛朗展开中 $\frac{1}{z-z_0}$ 项的系数 $a_{-1}$。 | ch04 |
| 留数定理 | 闭路积分等于 $2\pi i$ 乘围道内留数之和。 | ch04 |
| 辐角原理 | $\frac{1}{2\pi i}\oint\frac{f'}{f}dz$ 等于零点数减极点数。 | ch04 |
| 傅里叶级数 | 周期函数展开成三角函数的级数。 | ch05 |
| 傅里叶变换 | $F(k)=\int f(x)e^{-ikx}dx$，把空间描述换成频率描述。 | ch05 |
| 卷积 | $(f*g)(x)=\int f(\xi)g(x-\xi)d\xi$；频域里是乘法。 | ch05 |
| δ函数 | 单位脉冲，$\int\delta(x)\phi(x)dx=\phi(0)$。 | ch05 |
| 拉普拉斯变换 | $F(s)=\int_0^{\infty}f(t)e^{-st}dt$，用于初值问题。 | ch06 |
| 收敛域 | 拉普拉斯积分收敛的 $s$ 范围，通常是右半平面。 | ch06 |
| 传递函数 | 零初值下输出与输入在 $s$ 域的比值。 | ch06 |
| 波动方程 | $u_{tt}=a^2\Delta u$，双曲型，需要两个初始条件。 | ch07 |
| 热传导方程 | $u_t=a^2\Delta u$，抛物型，只需一个初始条件。 | ch07 |
| 拉普拉斯方程 | $\Delta u=0$，椭圆型，描述稳态场。 | ch07 |
| 泊松方程 | $\Delta u=-f$，有源的稳态方程。 | ch07 |
| Dirichlet 边界 | 给定边界上的函数值 $u=g$。 | ch07 |
| Neumann 边界 | 给定边界上的法向导数 $\partial_nu=g$。 | ch07 |
| Robin 边界 | 函数值与法向导数的线性组合给定。 | ch07 |
| 定解条件 | 初始条件与边界条件的统称。 | ch07 |
| 适定性 | 解存在、唯一、且连续依赖数据。 | ch07 |
| 分离变量 | 设乘积解把偏微分方程拆成常微分方程。 | ch08 |
| 本征值问题 | $X''+\lambda X=0$ 加齐次边界，只有离散的 $\lambda$ 有非零解。 | ch08 |
| 本征函数 | 对应本征值的非零解 $X_n$，构成展开基。 | ch08 |
| 正交性 | 不同本征值的本征函数内积为零。 | ch08 |
| 完备性 | 任意满足边界条件的函数都能按本征函数展开。 | ch08 |
| 冲量定理 | 受迫系统的解等于源与自由响应的卷积，也叫杜哈梅原理。 | ch08 |
| 达朗贝尔公式 | 一维波动方程用初始位移与速度写出的显式解。 | ch09 |
| 特征线 | 波动方程中 $x\pm at=$ 常数的曲线，信息沿它传播。 | ch09 |
| 依赖区域 | 影响某点取值的初始数据区间 $[x-at,x+at]$。 | ch09 |
| 延拓法 | 把半无界初始数据按奇偶对称延到全轴，用全无界公式求解。 | ch09 |
| 格林函数 | 点源引起的场，满足 $LG=\delta$ 与齐次边界。 | ch10 |
| 基本解 | 自由空间中点源的响应，不含边界修正。 | ch10 |
| 镜像法 | 在区域外放虚拟源，使边界条件自动满足。 | ch10 |
| 推迟势 | 源在 $t-r/a$ 时刻的作用在 $t$ 时刻到达场点。 | ch10 |
| 勒让德多项式 | 球坐标极角方程的有界多项式解 $P_l$。 | ch11 |
| 母函数 | $\frac{1}{\sqrt{1-2xt+t^2}}=\sum P_l(x)t^l$。 | ch11 |
| 罗德里格斯公式 | $P_l=\frac{1}{2^ll!}\frac{d^l}{dx^l}(x^2-1)^l$。 | ch11 |
| 连带勒让德函数 | $P_l^m$，含 $m\ne0$ 的极角解。 | ch11 |
| 球谐函数 | 球面上的正交归一基 $Y_{lm}$。 | ch11 |
| 贝塞尔函数 | 柱坐标径向方程的解 $J_\nu$、$Y_\nu$。 | ch12 |
| 修正贝塞尔函数 | $I_\nu$、$K_\nu$，描述指数增长与衰减。 | ch12 |
| 球贝塞尔函数 | $j_l$、$n_l$，可用正弦余弦除以 $x$ 表示。 | ch12 |
| 泛函 | 输入为函数、输出为数的映射。 | ch13 |
| 变分 | 函数发生小扰动时泛函的一阶改变量 $\delta J$。 | ch13 |
| 欧拉–拉格朗日方程 | 泛函取驻值的必要条件。 | ch13 |
| 哈密顿原理 | 真实运动使作用量 $\int L\,dt$ 取驻值。 | ch13 |
| 瑞利–里兹法 | 用试探函数代入泛函求本征值近似，结果从上方逼近。 | ch13 |
