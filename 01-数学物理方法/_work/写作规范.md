# 填充写作规范（v1，全书统一）

这份规范是 14 章精讲、61 个概念页、5 个深度片段的唯一口径。写之前通读一遍，交稿前逐条自查。

## 一、读者是谁

高中毕业、刚学完大一上学期微积分。会算一元积分，会基本偏导，但没学过复变函数，没解过偏微分方程。看到 $\Sigma$、$\nabla$ 会停顿，但只要有人用一句话说清"这是个求和符号""这是个求变化率的算子"，就能接着读。

不预设读者知道：解析、留数、分离变量、本征值、格林函数、勒让德多项式。

## 二、不能动的东西

- 章节 id、章节标题、章节顺序（ch00–ch13）不动。
- 概念 id、概念标题、所属章节、前置关系不动。现有 61 个概念一个不删，不新增。
- 目录结构、manifest 字段名、`index.html`、单书伴侣 HTML 都不手改；这些由主控统一重建。
- 只写分配给你的文件：
  - `chapters/chXX.md`（整篇重写）
  - `concepts/cXXX.md`（保留原有四块，追加详解）
  - `concepts/cXXX-depth.md`（只有指定概念写）
  - `_work/quiz_cards/chXX.json`（题与卡）
- 不要跑构建脚本，不要动 `manifest.json`、`extras_data.py`、`数学物理方法学习伴侣.html`、根目录 `index.html`。

## 三、全系统统一的符号

| 项目 | 统一写法 | 不许出现 |
|---|---|---|
| 傅里叶正变换 | $F(k)=\int_{-\infty}^{\infty}f(x)e^{-ikx}\,dx$ | $e^{+ikx}$ 当正变换、$\frac{1}{\sqrt{2\pi}}$ 分摊 |
| 傅里叶逆变换 | $f(x)=\frac{1}{2\pi}\int_{-\infty}^{\infty}F(k)e^{ikx}\,dk$ | 不带 $1/(2\pi)$ |
| 波动方程 | $u_{tt}=a^2\Delta u$ | $c^2$、$v^2$ |
| 热传导方程 | $u_t=a^2\Delta u$ | $\kappa$、$D$、$a$（漏平方） |
| 球坐标 | $(r,\theta,\varphi)$，$\theta$ 是极角（从北极量，$0\le\theta\le\pi$），$\varphi$ 是方位角 | 把 $\theta$ 当方位角 |
| 柱坐标 | $(r,\varphi,z)$（沿用现有文本用 $r$ 表示柱半径） | 新引入 $\rho$ 造成前后不一致 |
| 拉普拉斯算子 | $\Delta u=u_{xx}+u_{yy}+u_{zz}$ | $\nabla^2$ 与 $\Delta$ 混着写同一章 |
| 本征值 | $\lambda_n$，本征函数 $X_n$ | $\lambda$ 与 $k$ 混用指同一个东西 |

## 四、章节模板（`chapters/chXX.md`）

顺序固定，小标题照抄。每节只讲一件事，不写"本章将……""综上所述"。

```markdown
# 第 N 章：<原标题>

- **难度**：★★☆ | **预估学时**：X 小时 | **前置**：第 M 章

## 这一章解决什么问题
<两类问题：不学它，后面哪一步会卡死；学完它，能多算什么。2 段以内，给具体场景，不空转。>

## 学习目标
学完本章，你能：
- <动词开头、可被自测题直接考核，4 条左右>

## 一句话核心
<一句能背下来的话，含本章最关键机制>

## 零基础讲解
### N.1 <概念名>（cXXX，难度：基础/进阶/高难）
<白话定义（术语首现即解释）→ 为什么需要 → 公式/规则 → 一个带数字的例子>

### N.2 ...
<按概念链顺序展开，前置在前。每个小节 400–800 字，公式后面紧跟一句"这个式子说的是……"。>

## 图示
<至少一张结构化表格，或一个 mermaid 代码块 + "看图说明：这张图看什么、能得出什么结论"。表格里禁止裸写 $|z|$，用 \lvert z\rvert。>

## 类比与实例
- **类比**：<贴近日常 + 一句"这个类比在 X 处失效">
- **实例**：<完整数字例子，写出每一步，最后给出可复核的数值。读者拿纸能算通。>

## 常见误解
- 别以为 <错误认知>——实际上 <正确解释，附一句理由>。3–5 条。

## 自测题（答案）
1. <题干>
   **答案**：<...>　**解析**：<为什么，含关键一步>
   共 4–5 题，覆盖本章全部学习目标；至少一题针对常见误解。

## 复习锚点
- <2–3 条，过几天回来能一句话复述>

## 本章在全书的位置
<前置接哪、后续喂给哪；一段话。末尾一句"下一步"指向下一章。>
```

篇幅：每章正文 2500–4500 字（中文字符），难点章节（ch04、ch08、ch10、ch11、ch12）可以更长。

## 五、概念页模板（`concepts/cXXX.md`）

原有四块（一句话定义 / 它在体系中的位置 / 核心结论 / 常见误解）保留并可以润色，**新增"详解"块**，放在"核心结论"之后、"常见误解"之前。

```markdown
# <原标题>

- **难度**：<原样> | **涉及章节**：<原样> | **前置**：<原样>

## 一句话定义
<保留原意，可改顺>

## 它在体系中的位置
<保留，补一句"不懂它会卡在哪">

## 核心结论
<保留要点，每条后面可补半句解释>

## 详解

### 白话解释
<把定义翻译成日常语言。先给读者已经会的东西，再往上加一层。出现新符号就地解释。400 字左右。>

### 一个能验算的小例子
<带具体数字，写出中间步骤和最终结果。读者能自己算一遍并核对。禁止"容易验证"四个字了事。>

### 与相邻概念的区别
<挑 1–2 个最容易混的概念，说清边界：什么时候用哪个，混用会出什么错。>

## 常见误解
<保留并补充，2–4 条，格式"别以为……实际上……">

## 相关概念
<保留>
```

篇幅：每个概念 1000–1800 字。

## 六、深度片段模板（`concepts/cXXX-depth.md`）

只给指定概念写：c403、c802、c1001、c1101、c1201。文件名必须是 `concepts/cXXX-depth.md`。

要求：

- 从读者已有基础起推（复变部分从导数/积分起，数理方程部分从分离变量与常微分方程起，特殊函数部分从幂级数解法起），不引用读者没学过的定理。
- 逐步代数，每一步之间补出"为什么可以这样变"。
- 结构：问题是什么 → 需要哪些已有工具 → 完整推导（分步小标题）→ 一个数值算例（自己算过）→ 结论怎么用 → 常见卡点。
- 篇幅是概念正文的 2–3 倍（2000–4000 字）。
- 写完按下面四条自查，任何一条不过就补步骤：
  1. 这一步用到的概念前面解释过吗？
  2. 读者能在下一行之前自己写出这一行吗？
  3. 新符号第一次出现有没有白话解释？
  4. 结论讲了"为什么这样设计"吗？

## 七、题与卡的 JSON（`_work/quiz_cards/chXX.json`）

每章一个文件，UTF-8，结构如下。主控会用脚本合并进 `manifest.json` 并重生成 `quiz.md`、`flashcards.md`。

```json
{
  "chapterId": "ch04",
  "quizzes": [
    {
      "question": "题干，可含 $公式$",
      "options": ["选项 A", "选项 B", "选项 C"],
      "answer": 0,
      "explain": "解析：为什么对，其他选项错在哪",
      "relatedConceptId": "c403"
    }
  ],
  "flashcards": [
    {"front": "只放问题或线索", "back": "答案，一到两句", "tags": ["留数", "ch04"]}
  ]
}
```

硬要求：

- 每章 **至少 5 道新题**（现有每章已有 2 道，合并后达到 7 道）。
- 每题 3 个选项（也可以 4 个），`answer` 是正确选项的**下标**（从 0 开始）。
- 题干和选项里都要有具体数字或具体函数，不要"下列说法正确的是"这种空题。
- 答案自己算一遍。解析写关键一步，不写"显然"。
- 每章 **至少 5 张新卡**（合并后 8 张）。正面只放问题，答案不泄漏。
- `relatedConceptId` 必须是本章真实存在的概念 id。

## 八、语言与排版硬规则

禁用词/句式（出现即改）：

- "首先""其次""最后""综上所述""值得注意的是""不难发现""众所周知""显然"
- "本章将……""接下来我们……""让我们一起……"
- "不是 A 而是 B"的翻案腔（改成正面陈述）
- "核心是：""一句话总结："这类空转冒号
- 每段结尾重复上一句的总结句
- 三段以上连续排比、通篇"不仅……而且……"

其他：

- 一段只讲一件事，句子长短错开。
- 数学公式用 `$...$`；块级公式用 `$$...$$` 且单独成行。
- 公式里的 `<` 写成 `&lt;`（构建器会兜底，但手写时先转义更稳）。
- 表格单元格里不写裸 `|`，绝对值用 `\lvert z\rvert`。
- 中文与公式之间不加空格也行，但同一章内保持一致。
- 数字与结论必须自洽：每个"约为"后面都要能复算。
